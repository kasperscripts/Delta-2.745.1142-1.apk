# GrandProject_6231_fix — незавершённый черновик

**Премиум не разблокирован. Готовой APK для установки в этой папке нет.**

Повторная попытка без дополнительных файлов: принудительный успешный статус запуска и три искусственных ответа премиум-сервиса проверены на оригинальном нативном коде в ARM64-эмуляторе. Статус запуска удалось изменить на 1, но функция отрисовки осталась функцией загрузчика. Пустой ответ, `{"enabled":true,"premium":true}` и пустая пара `profile`/`signature` отклонены с `invalid signed Grand+ offset profile`; во всех случаях указатель и длина выходных данных остались нулевыми. Эти варианты обхода не включили премиум.

Подготовлены исходные правки для открытия `https://t.me/Icon_Crack` при входе и подписи `cracked by @Icon_Crack` на экране загрузчика и основной Activity. Открытие ссылки выполняется один раз на запуск Activity; возврат из Telegram и восстановление сохранённого состояния не должны создавать цикл переходов. Если обработчика ссылки нет, показывается адрес канала.

Изменённый DEX собран и повторно декомпилирован. На телефоне поведение не проверено. Видимость Java-подписи поверх нативной GL-поверхности также требует проверки на устройстве. Внутренние подписи и ссылки в загружаемом с сервера модуле ещё не изменены.

## Повторная проверка без дополнительных файлов

`probes/offline_probe.py` использует только исходную APK. Скрипт исполняет оригинальный распаковщик и все 646 конструкторов `libgrnd.so` в Unicorn, затем проверяет:

| Подстановка | Фактический результат |
| --- | --- |
| `nativeState()` заменён на `return 1` | Возвращает 1; callback отрисовки остаётся `0x49fb70` — экраном загрузчика. |
| Глобальный статус загрузки установлен в 1 | Возвращает 1; callback также не меняется. |
| RPC без сетевой сессии | Возвращает 0 и `Dev HTTP session required`; выходные данные отсутствуют. |
| Имитация успешного аутентифицированного ответа `{}` | Возвращает 0 и `invalid signed Grand+ offset profile`; выходные данные отсутствуют. |
| Имитация ответа `{"enabled":true,"premium":true}` | Та же ошибка и отсутствие данных. |
| Имитация ответа `{"profile":"","signature":""}` | Та же ошибка и отсутствие данных. |

Для имитаций использован оригинальный JSON-парсер и оригинальный обработчик ответа RPC. Подменён только транспорт; реальных запросов, токенов и ключей нет. Обход статуса запуска проверен исполнением изменённых инструкций, с очисткой кэша трансляций эмулятора. APK на диске не изменяется.

Воспроизведение:

```sh
python3 -m pip install unicorn==2.1.4 pyelftools==0.33
python3 grandproject/probes/offline_probe.py GrandProject_6231_fix.apk --output offline-results.json
```

Хеши APK и нативной библиотеки проверяются перед исполнением; адреса нельзя переносить на другие сборки. Файл `probes/offline-results.json` получен этим запуском. Эти эксперименты проверяют конкретные локальные подстановки и не доказывают невозможность всех иных способов изменения приложения. Полный жизненный цикл Android и работа меню на телефоне по-прежнему не проверены.
