## Файлы черновика

- `prepare_branding.py` применяет изменения к каталогу smali из исходного `classes6.dex`.
- `smali/com/iconcrack/Branding.smali` содержит переход в Telegram и Java-подпись.
- `Activities.patch` показывает изменения двух существующих Activity.
- `verification.json` фиксирует выполненные проверки и ограничения.

Для воспроизведения DEX-проверки с Apktool 2.12.1 и JADX 1.5.3:

1. Извлечь `classes6.dex` из исходной APK и поместить его в отдельный ZIP под именем `classes.dex`.
2. Декодировать этот ZIP: `java -jar apktool.jar d -r --no-assets -o dex6-src dex6-only.apk`.
3. Выполнить `python3 prepare_branding.py dex6-src/smali`.
4. Собрать контейнер: `java -jar apktool.jar b -o dex6-container.apk dex6-src`.
5. Извлечь новый `classes.dex` и повторно открыть в JADX.

Этот маленький ZIP-контейнер используется только для проверки DEX и **не является устанавливаемым приложением**.
